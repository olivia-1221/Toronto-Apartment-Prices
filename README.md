# Predictors of Toronto Apartment Prices

* `Toronto_apartment_rentals_2018.csv` is the dataset we obtained from [this Kaggle page](https://www.kaggle.com/datasets/rajacsp/toronto-apartment-price?resource=download).
* `Report.Rmd` contains our analysis and regression modeling of Toronto apartment prices in 2018 based on apartment characteristics. It renders into our final `Report.pdf`. It also produces `Report.html` (some of the formatting is messy though because the Rmd file was made to produce a PDF in particular).
