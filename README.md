# Predictors of Toronto Apartment Prices

* `Toronto_apartment_rentals_2018.csv` contains data on Toronto apartments in 2018, such as their monthly rental prices and the number of bedrooms, dens, and bathrooms they have. We obtained it from [this Kaggle page](https://www.kaggle.com/datasets/rajacsp/toronto-apartment-price?resource=download).
* `Report.Rmd` contains our analysis and regression modeling of Toronto apartment rental prices in 2018. It produces our final report: `Report.pdf`.
